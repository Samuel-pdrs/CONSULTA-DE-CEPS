# 📍 Localizador de CEPs de Carangola

## Sobre o projeto

O **Localizador de CEPs de Carangola** é uma aplicação web criada para
facilitar a busca por endereços e Códigos de Endereçamento Postal (CEPs)
do município de Carangola, em Minas Gerais.

A ideia surgiu a partir de uma atividade acadêmica: construir uma página
que trabalhasse com dados reais, permitisse pesquisas interativas e
apresentasse os resultados de maneira organizada.

Além da consulta de CEPs, o projeto reúne informações sobre a
organização postal do município, incluindo localidades, distritos e
referências úteis para quem precisa localizar um endereço.

## O que você encontra na aplicação

### 🔎 Busca de endereços e CEPs

Pesquise da maneira que for mais conveniente:

-   **Por CEP:** informe os oito dígitos do código para consultar o
    endereço correspondente.
-   **Por rua ou bairro:** digite o nome de um logradouro ou localidade
    e veja sugestões de resultados.
-   **Sugestões de busca:** a pesquisa por endereço apresenta opções
    para facilitar a escolha do resultado correto.

### 📌 Informações do resultado

Ao realizar uma consulta, a aplicação apresenta os dados disponíveis
para o endereço, como:

-   CEP;
-   logradouro;
-   bairro ou distrito;
-   município e estado.

Quando disponíveis, também são apresentadas informações complementares
para ajudar na identificação do endereço.

### 📋 Recursos para facilitar o uso

-   Copiar o CEP com um clique.
-   Copiar o endereço em formato organizado.
-   Abrir a localização no Google Maps.
-   Consultar o guia postal com informações sobre localidades e faixas
    de CEP.

## Guia postal de Carangola

Carangola possui diferentes localidades e áreas com características
próprias de identificação postal. Por isso, o projeto também apresenta
um guia de consulta com referências sobre a sede urbana, distritos e
zona rural.

Entre as localidades contempladas estão:

-   Sede urbana de Carangola;
-   Lacerdina;
-   Área Rural;
-   Alvorada;
-   Ponte Alta de Minas;
-   São Manoel do Boi.

O guia também reúne referências sobre unidades de atendimento dos
Correios e sobre códigos postais anteriores, conforme os dados
utilizados no projeto.

> **Atenção:** as informações exibidas têm finalidade informativa e
> acadêmica. Para envios, cadastros ou outras situações que exijam
> confirmação cadastral, confira o CEP nos canais oficiais dos Correios.

## Como funciona a consulta

A aplicação combina duas fontes de informação:

-   **Base de dados do projeto:** reúne registros locais utilizados para
    apoiar as pesquisas sobre Carangola.
-   **Serviços externos de consulta:** o ViaCEP e a BrasilAPI são
    utilizados para buscar informações de CEP e endereço, de acordo com
    o tipo de pesquisa e o funcionamento da aplicação.

Como os dados e os serviços externos podem ser atualizados, os
resultados devem ser entendidos como informações de consulta, e não como
garantia de atualização cadastral em tempo real.

## Sobre o desenvolvimento

Este projeto foi desenvolvido como atividade prática da disciplina
**Programação 2**, do curso de **Bacharelado em Sistemas de Informação**
da Universidade do Estado de Minas Gerais (UEMG), Unidade Acadêmica de
Carangola.

A proposta da atividade foi aplicar conhecimentos de desenvolvimento web
na criação de uma página interativa, com pesquisa de dados, apresentação
de resultados e adaptação para diferentes dispositivos.

### Tecnologias utilizadas

A aplicação foi construída com tecnologias fundamentais da web:

-   **HTML5** --- estrutura da página;
-   **CSS3** --- apresentação visual e adaptação para diferentes telas;
-   **JavaScript** --- pesquisas e interações;
-   **JSON** --- organização dos dados locais.

As consultas externas utilizam os serviços
[ViaCEP](https://viacep.com.br/) e
[BrasilAPI](https://brasilapi.com.br/).
