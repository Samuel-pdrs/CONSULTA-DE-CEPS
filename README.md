# Consulta Inteligente de CEPs --- Carangola/MG

Aplicação web para consultar CEPs, ruas, bairros e localidades de
Carangola, Minas Gerais.

**[Acessar aplicação](https://samuel-pdrs.github.io/CONSULTA-DE-CEPS/)**
· **[Ver repositório](https://github.com/Samuel-pdrs/CONSULTA-DE-CEPS)**

## Funcionalidades

-   Consulta de endereço por CEP.
-   Busca de ruas, bairros e localidades com sugestões.
-   Exibição e cópia dos dados do endereço.
-   Acesso à localização pelo Google Maps.
-   Guia postal com informações sobre a sede urbana, distritos e área
    rural de Carangola.

## Tecnologias

-   HTML5
-   CSS3
-   JavaScript
-   JSON
-   ViaCEP e BrasilAPI
